### Tool Call Patterns (Research Summary)

1. **Native tool support is best** - don't parse text if model supports structured tool calls
2. **JSON Schema** for tool definitions - detailed descriptions are critical
3. **XML-style delimiters** fallback only for text-only models
4. **Conversation loop**: assistant tool_use → user tool_result → assistant...
5. **Error handling**: Return structured errors with retry hints

## Option B: MiniMax Coding Agent (Native Tool Calling)

### Why This Is Better Than Expected

MiniMax-M2.7 has **native function calling** via the OpenAI-compatible API. We don't need to parse text output! This means:

- **Reliable tool calls** - structured JSON, not parsed from text
- **OpenAI SDK patterns** work directly
- **Standard tool format** - JSON Schema definitions
- **Clean loop** - model outputs `tool_calls`, we execute and return `tool_result`

```

miniMaxState.ts            # State management
```

### Session Loop Flow

```
1. User sends message
2. Append to messages array (with history)
3. Call OpenAI API: client.chat.completions.create({ model: "MiniMax-M2.7", messages, tools })
4. If response.tool_calls:
   a. Execute each tool in parallel
   b. Append assistant message (with tool_calls)
   c. Append user message (with tool_results)
   d. Goto step 3
5. If response.content:
   a. Stream content to user
   b. Append to messages
6. Return final response
```

## Important Notes (From Testing)

1. **MiniMax-M2.7 DOES support images** - the error was from Kilo (which doesn't support images). MiniMax-M2.7 has image support.

2. **mmx CLI vs Direct API**:
   - **mmx CLI** (`mmx text chat`):
     - Spawns subprocess, simpler setup
     - Has `--non-interactive` flag
     - Limited output format options (just text streaming)
   - **Direct API** (OpenAI-compatible):
     - Use `openai` npm package with `baseURL: "https://api.minimaxi.com/v1"`
     - Full control over streaming, tools, JSON mode
     - Proper tool_call support from MiniMax-M2.7
     - Better for complex agentic workflows (my recommendation)
   - **Both work** - for complex future features, Direct API is better. For simpler use, mmx CLI works.

3. **Both providers should support images**:
   - MiniMaxAgent via Direct API (MiniMax-M2.7 supports images)
   - KiloCode via ACP (need to check if Kilo ACP supports images)
